# Template para Desenvolvimento de Unidades usando o PPU da UNASUS

Os arquivos utilizados para esse template vieram inicialmente do repositório [[https://github.com/Gabriel-Lindner-Alvim/PPU-Prisional-Template]].

Neste repositório, foram descartados alguns arquivos desnecessários e outros foram levemente reformatados (eu sou mesquinha e quero que tudo esteja no formato que eu prefiro). A única mudança importante do repositório original para esse é a generalização do "template", este repositório está cru e preparado para dar início ao desenvolvimento de diferentes páginas.

Os pontos nos quais informações sobre a página a ser produzida devem ser inseridas no template estão indicados por comentários `TODO`. Comentários `mTODO` são direcionados para o desenvolvimento do template. Não é de se esperar que tais comentários existam em condições normais de operação.
